Glossary
========

.. glossary::
   :sorted:

   Databricks
      Unified analytics platform built on Apache Spark.

   SQL Warehouse
      Compute resource in Databricks for running SQL queries.

   HTTP Path
      Endpoint in Databricks for SQL warehouse connections.

   Access Token
      Authentication token for Databricks API access.

   ORM
      Object-Relational Mapping. Technique mapping database tables to Python objects.

   Query Builder
      Fluent interface for constructing SQL queries programmatically.
